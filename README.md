# PanteraLab

Aplicacao Next.js com MongoDB, NextAuth, Brevo, Cloudinary e Pusher. Em preparacao para uma comunidade catolica de oracao, com Rosario Guiado e Capelinha Virtual em etapas posteriores.

## Desenvolvimento

Node 22. Instale com `npm ci`, configure `.env.local` exclusivo de desenvolvimento a partir de `.env.example` e execute `npm run dev`.

Verificacoes: `npm test`, `npm run lint`, `npm run build`. Servidor de producao: `npm start`.

Consulte [a etapa 1 e o roteiro de homologacao](docs/etapa-1.md) para autenticacao, permissoes, servicos e limitacoes. Nao use banco ou credenciais de producao em testes.
